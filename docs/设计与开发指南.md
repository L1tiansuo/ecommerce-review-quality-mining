# 设计与开发指南

系统用于公开中文电商评论的教学与研究。源码包含中文注释，所有模块可直接编辑，无加密、无编译器锁定。

## 架构与目录

```
Vue 3 / Element Plus / ECharts
             │ /api/v1
Spring Boot 3.2 / Java 17
    ├── controller：认证、参数验证、统一响应、导出
    ├── service：导入事务、任务、指数入库、预警、查询
    ├── repository：参数绑定 SQL 与批量写入
    ├── config：JWT 与三角色访问控制
    └── client：纯 HTTP 算法调用
             │ 私有容器网络
FastAPI / scikit-learn（不连接数据库）
    ├── preprocess：脱敏、HTML 与空白清洗
    ├── sentiment：TF-IDF + 校准 LinearSVC
    ├── aspect：Aho-Corasick 词表匹配、局部极性
    ├── fake_rules：五条可解释风险规则
    └── qi：时间衰减、风险降权、贝叶斯收缩
             │
MySQL 8：仅业务服务读写
```

H2 的 MySQL 兼容模式仅作为本机无 Docker 时的开发与测试选项，正式 Compose 使用 MySQL 8。持久层使用 Spring JDBC 显式 SQL，方便核对批量导入与预计算查询；它是相对于实施手册 JPA 分层的实现差异，不改变接口或业务边界。

## 数据与计算口径

主数据来自用户提供的 yf_amazon。两遍扫描，按商品评论量筛选，清洗正文，去除完全重复。真实用户编号不落库。评论时间按固定权重分配到13个月，最大日期为2026-11-09。供应商是合成的；900000001至900000005是模拟剧本商品。manifest.json 和 scenarios.json 记录加工过程。

六维权重依次为0.28、0.12、0.15、0.13、0.17、0.15。维度内同评论多个特性先求强度均值，只计一次样本；时间衰减半衰期90天，刷评风险降权为1-p，收缩强度30。先验来自品类之前90天已发布维度得分中位数，无可用值时为0.55。无方面证据的维度仅使用先验，界面保留样本量。期末日期是显式输入，不使用当前时间参与指数计算。

刷评分数是规则风险，不是真假认定。风险分数≥0.3视为疑似刷评，默认用于R4占比统计。线上任务不处理真实用户标识，同用户规则只对调用中明确传入的模拟user_key有效。

预警R1指数低、R2维度低、R3近7天差评率相对之前28天上升、R4风险占比、R5维度较前期下滑。每商品合并一条最高级别预警，消息记录全部命中；7日内抑制重复，级别升高更新原预警。确认、忽略、已处理均需意见，采用条件更新防止重复处置。

## 接口文档

业务端 `/swagger-ui/index.html`，OpenAPI JSON `/v3/api-docs`。算法端开发模式 `http://127.0.0.1:8001/docs`。统一响应为code/message/data。所有业务数据接口要求Bearer JWT，JWT有效期30分钟。ADMIN可管理与处置，ANALYST可导入和挖掘，VIEWER只读。

算法`/v1/*`同步请求上限32KB。纯计算接口`/v1/index`必须由业务方传入reviews、params与priors；只给商品编号无法计算，因为算法端不读数据库。内部`/internal/analyze`与`/internal/index`供业务端单商品批处理，不受同步32KB限制；Compose中算法服务没有对外映射端口。

## 开发与验证

```
python -m venv .venv
# Windows: .venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
python -m pytest tests -q
python scripts/evaluate.py
python scripts/bench_qi.py
```

模型需要额外安装pandas进行训练。默认训练语料为ChineseNlpCorpus的online_shopping_10_cats，按清洗文本去重后留出1000条。源数据无商品ID，因此这个划分不是商品互斥划分。测试集只有正负标签，中性由置信度区间[0.4,0.6]工程近似产生。没有中性金标不能认定三分类验收达标。

人工方面标注格式为JSONL，每行含text及aspects数组，数组项包含feature_code、start、end、polarity；start/end为Python Unicode字符偏移，end不含。调用`python scripts/evaluate.py --aspects data/eval/aspects_gold.jsonl`。不得用规则自产标签替代人工金标。

## 已知边界

本版没有微调BERT、实时爬虫、工单状态机、整改复评、多平台或大模型在线摘要。摘要采用指标模板。未实现自动断点续跑与应用内调度；失败任务可以重新提交，已提交商品按周期与参数版本覆盖。备份脚本需自行按部署环境定时执行，数据归档与日志清理需运维执行。界面展示月度趋势；没有把月度值伪装成每日测量值。

参数、词表、模型与输入数据都影响结果。复核历史运行应保存数据库备份、seed及任务词表快照；替换模型文件前须保留旧模型。单个参数版本不应关联多个不同的模型文件或词表语义。生产级并发、版本锁定、数据归档和更严格的资源限额是继续优化方向。
