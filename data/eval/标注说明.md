# 方面标注说明（300 条）

## 要做什么

每条评论读一遍，判断它在评价**商品的哪个具体方面**，以及对这个方面的**态度**。
一条评论可能有 0 个、1 个或多个方面。

## 怎么填

在 `aspects_label.csv` 的「标注」列，按 `特性:极性` 写，多个用分号隔开：

```
续航:负;做工:正
包装:正
```

- 特性写中文名（见 `aspects_legend.csv`）或英文码都可以，中英文混用也行；
- 极性只有三种：`正` / `负` / `中`（也可以用 `1` / `-1` / `0`）；
- **只写评论里明确提到的方面**。泛泛一句「很好」「不错」没有具体方面，就留空；
- 不要根据星级去猜方面，只按文本判断；
- 拿不准的边界情况，写在「备注」列，标完一起讨论。

## 什么时候标「中」

「中」不是“不知道”，它有明确含义：**提到了这个方面，但没有明确褒贬**。三种情况都标「中」：

- 客观陈述参数或事实：`续航 6 小时`、`屏幕是 6.1 寸`、`一盒 20 包`；
- 只有弱评价词：`还行`、`一般`、`凑合`、`说得过去`、`中规中矩`；
- 提到但只是转述、无态度：`客服说要联系厂家`、`说明书上写的`。

**留空**只有一种情况：评论里根本没提这个方面，或者只有「很好」「不错」这类没有指向的总体评价。

> 一定要标「中」：算法对“命中方面但强度接近 0”的输出就是「中」，实测占命中数的 41%。如果金标里没有「中」，这部分会被判成错误，方面情感准确率会被压到 0.6 以下——那是统计口径造成的，不是模型差。


## 例子

| 原文 | 标注 | 说明 |
|---|---|---|
| 续航太虚标了，说 8 小时实际 4 小时就没电，不过做工还行 | `续航:负;做工:正` | 两方面、两种极性 |
| 快递很快，第二天就到了 | `配送时效:正` | 只提一个方面 |
| 续航 6 小时左右，充满要两小时 | `续航:中` | 只陈述事实、无褒贬 |
| 包装一般吧，没坏也没好 | `包装:中` | 弱评价词 |
| 一般般吧 | （留空） | 没提任何具体方面 |

## 分给两个人时

- 第 1–50 行**两人都标**（用来算 Kappa，检验标准是否一致）；
- 第 51–300 行按单双号各标一半。

## 标完

```bash
python scripts/import_labels.py      # CSV → data/eval/aspects.jsonl，会报错指出填错的行
python scripts/evaluate.py --aspects data/eval/aspects.jsonl
```
